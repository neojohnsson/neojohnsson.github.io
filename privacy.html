autoClipper – Privacy Policy

autoClipper is a personal desktop tool. Its only user is its owner (twitch.tv/qNeo_), who uses it to post their own Apex Legends clips to their own TikTok and YouTube accounts.

  • autoClipper uploads only videos the owner chooses, to the owner's own accounts, using the TikTok Content Posting API and YouTube API Services.
  • Login tokens are stored only on the owner's own PC (Windows Credential Manager). No data is collected, sent anywhere else, sold or shared.
  • Access can be removed at any time in autoClipper ("Log out"), in TikTok's app settings, or at myaccount.google.com/permissions.
  • autoClipper uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.
